사용 도움말

양양 물고기반 공유 폴더 업로드용 파일 이름 일괄 변경 앱입니다.

1. 기본 사용 흐름

  1. + 폴더 선택 → 이미지/동영상이 있는 폴더 선택
  2. 기본 정보 입력 (지역, 포인트, 촬영자, 날짜) — 선택 사항
  3. 물고기 이름 입력 후 Enter로 변경 & 다음
  4. 분류하지 않을 파일은 스킵 버튼으로 Skip 폴더로 이동

2. 파일 이름 형식

{원본코드}_{물고기}_[지역포인트]_[촬영자]_[날짜].확장자

예: IMG_1234_황점개볼락_남애밸리_김철수_20250607.jpg

3. 기본 정보 항목

항목설명예시
지역/접두사촬영 지역남애, 북애, 동애, 서애
포인트이름세부 지점밸리, 구선미
야간체크 시 포인트 뒤에 N밸리N
촬영자이름촬영자홍길동
촬영일자8자리 (YYYYMMDD)20250607

4. 물고기 관련 옵션

  • 유어(J) — 치어/유어일 때 파일명에 J 접미사
  • 이름 불명확/모름 — 종을 특정하기 어려울 때 (물고기)로 표시

5. 키보드 단축키

키동작
Enter파일명 변경 후 다음 파일로
← →이전 / 다음 파일
ESC확대 뷰어 닫기

6. 확대 보기

이미지/동영상을 클릭하면 확대 뷰어가 열립니다. 더블클릭 확대, 두 손가락 스퀴즈로 줌, ESC로 닫기.

💡 Tip — 기본 정보는 앱을 다시 켜도 저장됩니다. 오늘 날짜 버튼으로 촬영일자를 빠르게 입력할 수 있습니다.
